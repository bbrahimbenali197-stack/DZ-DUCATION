Comment l’accès commercial doit fonctionner

1. Le parent choisit une formule

Il sélectionne le niveau, la durée et le nombre d’enfants, puis consulte les conditions.

2. Le paiement est confirmé

Une solution de paiement ou une procédure manuelle clairement définie confirme la commande.

3. L’administration remet le code

Le code est associé à la formule et à sa durée, puis transmis au client.

4. Le client active son accès

Le système vérifie le code et sa date d’expiration. Cette vérification doit être côté serveur pour sécuriser réellement les accès.

Important avant toute vente : cette page présente un modèle commercial et des prix suggérés, mais ne collecte pas de paiement, n’émet pas automatiquement de codes et ne gère pas encore l’expiration des abonnements. Sur un site GitHub Pages seul, les codes et les contenus protégés dans JavaScript ne sont pas confidentiels. Pour vendre de façon fiable, il faudra connecter un système d’authentification et une solution de paiement, ou utiliser une plateforme d’adhésion externe.

Questions fréquentes

Les prix affichés sont-ils définitifs ?

Non. Ce sont des propositions de départ en DA, à valider selon le contenu final, les coûts et le public visé. Modifiez-les avant publication commerciale si nécessaire.

Un abonnement est-il activé automatiquement ?

Pas encore. Il faut relier la commande, le paiement, la création du code et la date d’expiration à un système fiable.

Les parents peuvent-ils voir les progrès depuis leur téléphone ?

Les outils locaux ne synchronisent pas encore les données entre plusieurs appareils. Un espace partagé sera nécessaire pour un vrai suivi familial.

Les cours en ligne sont-ils déjà réservables et payables ici ?

La page permet de découvrir l’espace enseignants, mais la réservation, le paiement et les rappels automatiques restent à mettre en place.

4. Acheter un accès : procédure manuelle

Avant le paiement : les tarifs affichés sont des propositions à confirmer. Contactez l’administration pour connaître les modalités de paiement disponibles. Après vérification du paiement, l’administration envoie le code et la durée correspondante manuellement.
