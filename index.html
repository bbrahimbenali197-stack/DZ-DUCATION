👨‍👩‍👧 متابعة محلية

لأن TAALIM DZ يعمل على GitHub Pages دون قاعدة بيانات، لا يوجد تسجيل دخول أو مزامنة بين أجهزة مختلفة. يمكن للولي مراجعة خطة المراجعة والنتائج المحفوظة على الجهاز نفسه، أو تصدير ملف التقدّم ومشاركته يدوياً.

لا تدخل معلومات شخصية حساسة في الملفات المصدّرة. حذف بيانات المتصفح قد يمحو التقدّم المحفوظ.

أسئلة شائعة

معلومات مهمة قبل الاستخدام والنشر.

هل المنصة مجانية؟

نعم، هذا الموقع ثابت ومجاني للاستضافة عبر GitHub Pages ضمن حدود الخدمة.

هل أحتاج إلى حساب أو رمز دخول؟

لا. أزلنا رموز الدخول الوهمية لأن الموقع الثابت دون خادم لا يستطيع التحقق منها بأمان. الموارد العامة متاحة للجميع.

هل يتزامن التقدّم مع هاتفي أو جهاز آخر؟

لا. الخطة والنتائج تحفظ محلياً في المتصفح. استخدم زر التصدير لحفظ نسخة JSON يدوياً.

كيف أضيف دروساً وامتحانات جديدة؟

أضف ملف PDF إلى مجلد pdf/، ثم أضف وصفه ومساره في resources.json وادفع التغييرات إلى GitHub.

هل كل الملفات رسمية؟

لا. الملفات المرفقة أمثلة تدريبية أصلية. لا تنشر مواد محمية بحقوق النشر دون إذن، ووضّح مصدر أي ملف تضيفه.
